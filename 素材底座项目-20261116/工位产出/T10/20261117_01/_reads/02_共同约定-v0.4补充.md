## 三层数据

片段库里每条记录写明来自哪一层：

- **事实层**：人确认过的。只对确认的那个文件、那几秒、那个人有效，保持原样的起止时间。
- **粗标层**：现成的机器标签和目录名。用来缩小范围。
- **精标层**：按《素材标注总纲》看图标出来的。

机器标签和人工结论说法不同时，两条都留，人工的优先。

## 按通用的做法做

这套东西将来要给别的企业用，所以：

1. **地址、库名、人名放进配置。** 共享盘地址、库的别名、出镜人名字，写在 `片段库\配置\` 下的 JSON 里，脚本从配置读。
2. **每一步是能重复跑的脚本。** 同样的输入再跑一遍得到同样的结果。脚本放进产出文件夹的 `脚本\`。
3. **标签注明属于哪一层词表**：行业通用、品类专有、企业专有。拿不准的标“待定”。
4. **回报里多写一段“花了多少”**：用了多长时间、哪一步最慢、哪里需要人、花了多少钱（没花写 0）。

## 谁往哪里写

- 你的全部产出放在 `工位产出\<任务号>\<日期>_<批次>\`，自己新建。

## 这台电脑上的注意事项

- Python 在 `C:\Python314\python.exe`，没有 pandas 和 openpyxl。运行前设 `$env:PYTHONUTF8=1` 和 `$env:PYTHONDONTWRITEBYTECODE=1`。
- 脚本一律写成 `.py` 文件再运行。PowerShell 里 `python -c` 会吃掉代码里的双引号。
- 读 Excel 用 `..\..\素材标注总纲-20261116\_工具\xlsx_dump.py`。
- SQLite 文件用只读方式打开：`sqlite3.connect("file:<正斜杠路径>?mode=ro&immutable=1", uri=True)`。
- 共享盘上的数据文件先复制到自己的产出文件夹再处理，网络路径上的 SQLite 直接打不开。
- ffmpeg 和 ffprobe 已在 PATH 里。7-Zip 在 `C:\Program Files\7-Zip\7z.exe`。
- 共享盘用 UNC 路径访问。`Z:` 盘不用。
