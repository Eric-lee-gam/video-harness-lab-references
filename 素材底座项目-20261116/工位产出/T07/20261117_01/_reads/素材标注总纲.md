## 一、这套标准要回答什么

选镜单问的是“这句话要哪类画面”。现有标注库回答的是“这条片是什么材料、什么工序”。两边对不上。

新标准让每个可用片段都能回答五个问题：

1. 这是哪类画面（对应选镜单的 24 类）
2. 在哪、拍的什么、处在翻新的哪个阶段
3. 画面里有谁
4. 好不好剪（哪几秒能用、动作完不完整）
5. 能不能用（权利、打码、水印）

## 二、四条基本规则

1. **标在片段上。** 画面类的标签标在“原片 + 起止秒”上，不标在整条原片上。来源、权利这类标在原片上。
2. **只能从固定选项里选。** 每个维度都有“看不清”这一项。自由描述只当备注，不参与检索。原因：标注库现有的 15.4 万段机器描述是开放式提问得到的，大量是“男子在卫生间内，从站立到转身，动作连贯”这种句子，查不出东西。
3. **只标看得见的。** 材料品名、人物身份、是不是同一户，这三样画面本身证明不了，必须写依据等级，模型不许猜。
4. **每个标签带出处和版本。** 出处分目录、机器、人工三种。人工结论不被机器覆盖。这条沿用陈瀚文的做法。

### A 组：身份与来源

**A1 文件指纹**

- 原片 ID：沿用标注库的 ID

- 重复组：同内容的副本、同一画面的不同处理版本（去水印版和原版）归成一组，只留一条进入选材

**A2 来源**

- 可用状态：可用 / 需打码后可用 / 仅限该客户自己的片子 / 禁用。李康已定（2026-11-16）：扒扒库网采素材都可以复用，和中源素材所有账号可用，客户素材里没有人物的画面可以复用，详见《专有词表》第四节

- 是否有人脸、门牌、车牌：有 / 无 / 看不清

**B2 空间**（单选）

卫生间 / 厨房 / 客厅餐厅 / 卧室 / 阳台 / 楼梯过道 / 入户门口 / 小区楼栋外 / 城市街景或地标 / 展厅 / 车旁或仓库 / 样板台 / 室内，分不清房间 / 看不清

空间先从文件夹名和整条视频的信息带出，看图的模型只做核对。原因：试标 50 段里模型有 21 段填了“看不清”，施工特写只看得见一面墙或一块地；李康能补出来的空间，靠的是认识这户房子。模型只在看见马桶、灶台、床、沙发这类东西时才填具体房间，只凭地漏、管口、瓷砖不填。

**B3 部位**（单选）

墙面 / 地面 / 顶面 / 墙角与交界 / 台面柜体 / 洁具 / 门窗 / 样板 / 料桶 / 无（主体是人或整个空间）

**B4 阶段**（单选）

旧状（未动工） / 拆除铲除中 / 保护与基层处理 / 上料施工中 / 罩面收尾 / 安装收口 / 施工中途（没人干活） / 完工空房 / 入住使用 / 非现场 / 其他 / 看不清

- 按“面层做到哪一步”判，不看有没有人住。住着人的旧房是旧状。
- “安装收口”（正在装柜体、洁具）和“施工中途（没人干活）”是 v0.2 新加的，来自李康审核时写的“正在安装橱柜”“施工中，尚未完工”。
- 滚筒在旧瓷砖、旧墙面上是保护与基层处理，在已经同色成形的面上是罩面收尾。
- 人在房子里对镜头讲话，阶段按房子的情况填，不填非现场。
- 每个选项的定义见《看图标注任务说明》v0.2。

**B5 人物**

- 人数：0 / 1 / 2 / 3 以上。按人最多的那一帧数；只露出手脚也算，拍摄者伸进画面的手脚也算；倒影和远处的路人不算
- 角色（可多选）：主讲人 / 工人 / 客户业主 / 长者 / 儿童 / 路人 / 只见手脚
- 朝向：看镜头 / 露脸但不看镜头 / 背面 / 看不见头脸 / 无人。按视线判，不按身体朝哪边
- 是否在说话：是 / 否 / 看不清（用来避开口型冲突）
- 身份：阿明 / 李总 / 小羊 / 徐经理 / 美女姐姐（业主） / 客户方人物 / 未确认。按秒段记，不按整条视频记。来源只有三种：人工看图确认、文件夹名写明且词表已确认、本机人脸比对程序判为“像阿明”；大模型不按长相认人，程序分数低的记“未确认”而不是“不是”。叫法和对应文件夹见同文件夹的《专有词表》，办法和验证数据见《人物身份确认办法》

### C 组：剪辑属性

**C1 镜头**

- 画幅：竖 / 横
- 景别：特写 / 近景 / 中景 / 全景 / 远景
- 机位：平拍 / 俯拍 / 仰拍
- 视角（C1a，第一轮就做，李康 2026-11-16 定加）：第一视角 / 旁观拍摄 / 看不清。第一视角指拍的人自己的手、脚或身体伸进画面，边拍边指、边拍边摸、边走边看。没看到拍摄者的手脚入画，一律算旁观拍摄
- 运镜：固定 / 推 / 拉 / 横移 / 跟随 / 摇 / 明显晃动

**C2 可剪性**

- 可用起止秒
- 可用时长：不足 1 秒 / 1–2 秒 / 2–4 秒 / 4 秒以上（爆款单镜中位 1.3 秒，91% 不超过 2 秒）
- 动作完整：有起有收 / 只有中段 / 无动作
- 主体清楚：清楚 / 被遮挡 / 虚焦或过暗 / 晃得不能用
- 剪口线索（可多选）：遮镜 / 转身 / 入画 / 出画 / 收刀停稳 / 推门揭示 / 无
- 转场镜头（C2a，第一轮就做，李康 2026-11-16 定加）：是 / 否。“是”指这一段里有拍的人有意做的、用来接上一个或下一个镜头的动作：手或物体盖住镜头、手从镜头前划过、对着镜头比手势后画面空掉、推门露出房间、转身带出后面的画面。开头或结尾的全糊、全黑、纯色帧先当遮镜看，不当废帧。标注库里小区库已有 1,940 段带转场动作词，可以拿来对照

**C3 画质瑕疵**（可多选，带位置和秒段）

无 / 平台水印或账号 / 平台尾卡 / 烧录字幕 / 后期贴纸标签 / 消字涂抹痕迹 / 低清 / 他方品牌包装入镜

“他方品牌包装入镜”的片段一律不进入选材。来由：嘉贝乐相关素材（G200、G300）材料归微陶泥，但李康要求出现嘉贝乐产品包装的素材不要用（2026-11-16）。嘉贝乐相关目录的素材，在这一项标完之前不进入选材。

**C4 声音**

无音轨 / 只有环境声 / 有人说话（附机器转写） / 可作原声口播（人工确认）

### D 组：用途

**D1 可配句意与举证等级**

- 可配句意：不手标。由 B1 查句意画面对照表得出，分“爆款常用”和“爆款用过”两档
- 举证等级：示意 / 可举证。可举证只有四种情况：同户前后成对、具名料桶同框、砖缝可见的批刮、和性能一一对应的演示（弯折对韧性、刮擦对耐磨、喷水对防水）

标注只记录事实和举证等级，不替选镜做取舍。哪类句子必须用“可举证”的镜头，写在选镜规则里，现在的依据是 L04 那张表。

**D2 同户配对**

旧状片段和完工片段的配对编号，条件是同项目、同空间、能对上门窗或洁具位置。只认人工确认。

**D3 使用记录**

用过它的成片（批次、账号、日期）、当时配的句子、审片结论和原因。

### 每个标签都要带的状态

- 把握：确定 / 不确定
- 审核状态：未审 / 互检一致 / 抽审通过 / 人工确认 / 人工改正

三个要注意的事实：

- **扒扒的文件名标签不能用。** 按文件夹核对：`拆砸` 文件夹里标签带“拆砸”的只有 30%，`铺瓷砖` 19%，`7老人` 24%，`铲墙皮` 和 `8老房子` 是 0。`拍摄` 里的标签是照文件夹名生成的（搅拌、弯样本 100%，人物出镜 98%），等同于目录信息。所以只把文件夹名当线索，文件名标签不采用。
- **现有机器描述是本机小模型开放作答的。** 脚本里用的是 Qwen3-VL-2B，提问是“用一个简短的中文句子如实回答”。新标准改成从固定选项里选。

## 五、谁来标：分工

| 角色 | 做什么 | 用不用模型 |
|---|---|---|
| 入库员 | A 组、C4、画幅；归重复组 | 不用，脚本 |
| 切段员 | 把原片切成候选片段。先用标注库现成的时段和机器动作片段，超过 4 秒的再按动作点切开 | 不用，脚本 |
| 画面员 | B1、B4、C1a 视角、C2a 转场镜头；B2 只核对 | 看图 |
| 人物员 | B5（只看画面员判为有人的片段） | 看图 |
| 施工员 | B6、B3、B7 的基层（只看施工类片段） | 看图 |
| 镜头员 | C1、C2、C3 | 看图 |
| 互检员 | 跑一致性规则；对不确定的和抽样的片段换一个模型或换一种问法重判，不给它看第一次的结果 | 规则 + 看图 |
| 规则员 | 汇总审核原因，提出规则修改，跑回归 | 主智能体 |

看图的四个角色共用同一份抽帧拼图。小区库每段已有约 1 秒一帧的带时间戳拼图，不用重新抽帧。新抽帧时有两条要求（来自 50 段试标）：按视频的旋转信息把画面转正；帧数不足时在空位上印“无帧”，免得和遮镜的纯色帧混起来。

每个看图角色的输出格式固定：选项、一句“看见了什么”、把握、拿不准的地方。说不出看见了什么的，一律填“看不清”。“把握”只针对画面类型；其余各项拿不准就直接选“看不清”，不算猜。原因：试标里 34 段标了“不确定”，其中 31 段画面类型是对的，拿不准的多是空间和阶段，混在一起会让要人看的段数虚高。

一致性规则（互检员自动跑，不一致的进人工队列）：

- 画面类型是批刮覆盖，动作必须是批刮，阶段必须是上料施工中
- 画面类型是滚涂，动作必须是滚涂或刷涂，阶段必须是保护与基层处理或罩面收尾
- 画面类型是成品空间，人数必须是 0，阶段必须是完工空房或入住使用
- 画面类型是成品里的人，人数至少 1，阶段同上
- 画面类型是人物对镜头，人数至少 1，朝向必须是看镜头
- 画面类型是旧房旧态，人数必须是 0，阶段必须是旧状
- 人数是 0，朝向必须是无人
- 动作是遮镜，转场镜头必须是“是”
- 文件夹是 `人物出镜` 而人数是 0
- 标注库里人工确认是批刮的片段，画面类型却不是批刮

## 六、人工审核

**怎么审。** 按画面类型分页，一页 50 段，每段显示抽帧拼图和机器给的选项。人只做两件事：点出不对的，选一个原因。这个形式沿用陈瀚文的疑难分组复核页（按“编号 + 判断”反馈）。同一类放在一起看，错的很显眼。

**审多少。**

- 第一轮试标 200 段，全部审
- 之后每批：互检不一致的全审，“不确定”的全审，其余每类抽 30 段
- 某一类连续两批抽审准确率到九成以上，抽审降到每类 10 段

**通过的原因**（必选一个）

| 代码 | 含义 | 之后怎么用 |
|---|---|---|
| T1 | 典型，一眼就是这类 | 进正例库 |
| T2 | 是这类，但在边界上 | 进边界例库，写明边界在哪 |
| T3 | 是这类，而且画面好，值得优先选 | 进正例库，加优先标记 |

**不通过的原因**（必选一个，可加一句备注）

| 代码 | 含义 | 之后怎么处理 |
|---|---|---|
| F1 | 类型判错，应为另一类 | 进反例库；记入混淆对 |
| F2 | 一段里有两种画面 | 退回切段员拆开 |
| F3 | 起止秒不对，切在动作中间 | 退回切段员 |
| F4 | 抽帧看不出来，要看原片 | 加密抽帧后重判 |
| F5 | 定义本身说不清，两类都说得通 | 交规则员，改定义 |
| F6 | 没有合适的选项 | 交规则员，考虑加选项 |
| F7 | 模型猜了它看不见的东西（身份、材料、同户） | 进反例库；加禁止项 |
| F8 | 漏了水印、字幕、打码要求 | 补 C3、A3 |
| F9 | 类型对，但画面不能用（糊、晃、遮挡） | 改 C2 |

每条审核记录保存：片段、证据图、机器选项、人工选项、原因代码、备注、当时的规则版本、审核人、日期。

## 七、迭代机制

**两个循环。**

- 内循环（每批一次）：标得对不对。数据来自上面的人工审核。
- 外循环（每周一次）：选得好不好用。数据来自剪辑和审片：AI 选中又被人换掉的镜头、审片返修的原因、放行的原因。回填到 D3，并用来修句意画面对照表。

**三个库。**

- 判例库：每一类的正例、反例、边界例，带原因。看图角色每次判之前先看本类的判例。
- 金标集：人工确认过的片段，只增不改。起步是标注库的 264 个精标片段和第一轮审过的 200 段。
- 变更记录：每次改规则写一行，见下。

**每批要出的数。** 每类的准确率、“看不清”占比、“其他”占比、最多的三个混淆对、最多的三个原因代码。

**什么情况下改规则。**

| 信号 | 动作 |
|---|---|
| 某类准确率九成以上 | 这一类放量，抽审减少 |
| 某类准确率在七成五到九成之间 | 改这一类的定义或判例，只重跑这一类 |
| 某类准确率低于七成五 | 这一类停标，重新定义或拆类 |
| 同一个混淆对一批里出现 5 次以上 | 给这一对补判定要点和反例 |
| F5 或 F6 一批里出现 5 次以上 | 必须出一条规则修改 |
| “其他”超过一成 | 从里面归纳新选项 |
| “看不清”超过两成 | 检查抽帧密度或换模型 |

这些门槛是起步值，跑过两批后按实际情况调整。

**改规则的纪律。**

- 每次修改先在金标集上回归：改完以后每一类的准确率都不能下降，下降就不合并
- 拆类、并类、加维度只在版本号进位时做（v0.1 → v0.2）；已标的片段保留原版本号，只重标受影响的类
- 变更记录每行写：日期、触发的原因代码和次数、改了什么、回归结果
