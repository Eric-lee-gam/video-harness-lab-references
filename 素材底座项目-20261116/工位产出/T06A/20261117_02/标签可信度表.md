# 标签可信度表（T06A / 20261117）

本表把粗标层里能对上《素材标注总纲》v0.2 的字段，逐个和事实层里**独立的**人工确认比。
时间重叠规则与 T10 相同：同一文件（路径规范化后大小写不敏感），两边都有起止秒，且 `起A < 止B 且 起B < 止A`。
只比「有时间重叠」的事实；比的条数少于 20 的字段结论写「样本不足」，不给百分比。
正例错 = 标签说「是」而人确认「不是」（或人确认是另一类）。漏标错 = 人确认「是」而重叠的粗标没标上。一条事实可以两种错都有，此时不算一致。

## 哪些事实拿来比，哪些不比

- 拿来比：试标 50 段（李康审过的画面类型；「对」用原类型，「错」用改正后的类型）、镜序/施工动作样例（正例或反例）、逐段事实里的 `confirmed_action` / 产品身份、标注库「人工确认片段」里写明的材料。
- 不比：确认状态为「暂定」的；没有完整起止秒的；目视纠正、文件夹级/格子级确认（对人身份，且多数无起止秒）。
- **尤其不比**：`标注库精标indexed_segments` 和 `本轮看片精标`。它们和粗标层的用途片段/索引是同一套标注库数据，拿来当「人工对照」会循环自证。
- 打磨没有对应的 B1 画面类型，不进入工序对照。含糊的「微陶泥施工」也不进入工序对照。
- 工序对照只纳入工序字段能表达的画面类型（V05 批刮、V06 滚涂、V07 铲修、V08 拆砸、V09 覆膜、V10 保洁、V11 材料桶、V23 施工现场·其他）。人确认是成品空间、人物对镜头等类型时，不算工序漏标。
