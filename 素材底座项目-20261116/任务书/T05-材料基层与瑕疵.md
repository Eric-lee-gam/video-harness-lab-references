# T05 材料、基层与瑕疵

先读 `..\共同约定.md`，再读 `专有词表.md` 第二节（材料）和 `素材标注总纲.md` 的 B7、C3。

## 目的

给片段补三样东西：用的是什么材料（带依据等级）、盖在什么基层上、画面有没有不能用的瑕疵。

## 输入

- T02 的拼图和片段表。
- 标注库里现成的材料字段、画面文字位置、瑕疵区间（只读）。
- 陈瀚文已有的材料裁定（料面有颗粒算微岩石、室外排除微陶泥、滚筒在无缝饰面上算上罩面），沿用，不重判。

## 步骤

1. **材料：沿用，不重判。** 把标注库的材料结论按词表的标准叫法归并，填材料类目和依据等级（目录标称 / 包装可见 / 质感判断 / 人工确认 / 无）。
   完成标准：本批每个片段有材料类目和依据等级；词表里“未确认”的类目原样标“未确认”。
2. **基层：看图判。** 只判施工类片段：旧瓷砖且砖缝可见 / 旧瓷砖但砖缝看不见 / 水泥或腻子 / 网格布 / 已成形饰面 / 样板 / 看不清。
   完成标准：施工类片段全部有基层；判为“旧瓷砖且砖缝可见”的抽 30 段，写明砖缝在图里的位置。
3. **瑕疵：先沿用再看图。** 平台水印或账号、平台尾卡、烧录字幕、后期贴纸、消字涂抹痕迹、低清、他方品牌包装入镜。
   完成标准：嘉贝乐相关目录的片段全部过了“他方品牌包装入镜”这一项；扒扒库的片段全部过了水印和字幕这两项。

## 验收标准

- 材料一栏没有任何一条是看图新猜出来的品名。
- 依据等级无空值。
- 标了“他方品牌包装入镜”的片段，全部附上能看见包装的那一帧。
- 回报里给出每种瑕疵的条数和各材料类目的条数。

## 这个工位特有的上报情形

- 桶身、包装上出现词表里没有的品牌或型号。
- 标注库的材料结论和画面明显矛盾（比如标微陶泥，画面却是室外）。
- 性能演示类片段（泼水、刮擦、弯折）看不出用的是哪种材料：标“未辨明”，并单列清单，这类镜头要李康或陈瀚文指认。
