# 问题单模板

文件名：`<日期>_<任务号>_<一句话>.md`，例如 `20261117_T03_批刮和补缝分不开.md`。一个问题一份。

```
任务号：
批次：
规则版本：

问题是什么（一两句）：

出现了多少次，占本批多少：

例子（片段编号，最多 5 个）：

卡在哪条规则上（文件名和小节）：

我现在是怎么处理的（已按现行规则做完 / 这部分先跳过了）：

我的建议（可以不填）：

要谁来定：总控能定 / 要李康定 / 要陈瀚文或张艺确认
```

总控收到后在同一份文件末尾写“处理结果”：改了哪条规则、记进了哪份改动记录，或者为什么不改。要李康定的，总控攒成一张清单集中问，不一条一条问。
