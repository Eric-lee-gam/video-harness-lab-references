# 自动启动与异常恢复

计划任务：`CutFrame-Studio-AutoRecover`。

- 当前 Windows 用户登录后隐藏运行，不打开浏览器；锁屏不影响服务。
- 保留当前用户共享盘权限，不保存登录密码。未登录 Windows 时不保证服务可用。
- 守护每5秒检查服务进程与端口；进程异常退出自动启动，已有实例不重复启动。
- 计划任务每分钟补启动守护，守护单实例；任务自身还配置失败重试。
- 不因接口繁忙超时杀进程；本方案处理进程退出，不承诺修复所有死锁。
- 点击关闭工作台会写入主动暂停标记，守护尊重暂停；再次启动工作台解除暂停。
- 日志保存在 `local/cutframe/server-logs`，每次服务启动使用独立日志，保留旧日志。
- 本机：http://127.0.0.1:4380/；同事：http://192.168.110.160:4380/。
- 自动恢复服务不代表自动重跑中断的配音、导出任务；需在网页检查任务状态。

2026-11-16 实测：空闲时终止服务，5.1秒恢复，进程号变化。未执行整机重启测试。
