### RC01 · 文案

按目标选择开头：成本范围、同城疑问、人物故事、生活体验、行业冲突各成一类，不固定一套开头。

适用条件：受众问题和业务信息明确；人物身份及案例真实；预测和行业判断不得无依据复刻。

例片：R01 0–4.8s 价格+厨卫范围；R03 0–4.25s 同城疑问；R04 0–3.125s 第一人称生活体验；R08 0–4.767s 亲情案例；R10 0–2.6s 行业冲突候选；R23 0–4s 新增人物夸张钩子，受众适用性待检验；R25 0–2.533s 同城行业冲突进入团队服务

缺少输入：新片目标与核实后的业务主张；人物案例身份

状态：编辑判断候选，待代表样片验证；尚未证明原素材库可满足。

### RC02 · 文案

把服务范围、工期、价格、环保与性能拆成逐项需证主张，不从模板继承数字。

适用条件：按实际面积、工序、养护和服务条件核实。

例片：R01 16.667–21.133s 卫生间3天、厨房2天表达；R05 8.167–10.708s 卫生间7天表达；R06 8.967–12.967s 1到2万元、7天表达

缺少输入：价格构成、工期条件、检测报告、入住/使用条件

状态：编辑判断候选，待代表样片验证；尚未证明原素材库可满足。

### RC03 · 文案

结尾按动作目标选择点赞、咨询或结果收尾；咨询明确入口、所需信息与后续服务。

适用条件：平台入口有效且服务可履行；效果需新片验证。

例片：R01 29.633–30.881s 点赞；R06 20.167–24.821s 头像→位置→免费上门方案；R18 22.083–24.083s 有需要请直接找武汉阿明；R20 19.958–23.753s 评论旧房翻新→免费上门出方案；R25 16.133–19.202s 点赞→免费量房方案，两种目标要区分

状态：编辑判断候选，待代表样片验证；尚未证明原素材库可满足。

## 可执行性与待核验

- 现在可用于流程设计：开头类型、语义镜头需求、正负方向、分镜职责和审核字段；每条均能回溯参考片。
- 原素材库可读但尚未索引/标注，没有核实哪些具体源区间可满足这些规则，不能承诺已可批量制作。
- 声音原文需要全轨听辨并校准术语、重音/语速/BGM/音效；切点与动作需要连续观看和逐帧复查。
- 真实同户前后、人物关系、地域、材料身份、性能/环保/寿命、价格/工期及免费服务条件缺独立来源。
- HYPIT/OpenMontage仍仅源码和基础环境就位，没有集成生产；0/100新片，不改旧ASTRA审批、不外传源。
