## 我从两类资料共同理解的内容逻辑

主卖点不是单独的材料名，而是旧房改造的四个顾虑：拆除费用、搬家与打扫负担、工期和结果是否好看。材料覆盖动作负责解释如何少拆砸；保护、搬运、清洁、沟通负责解释谁来承担麻烦；成品与生活镜头负责让结果可想象。

文案先选择一种受众入口，视频再匹配有功能的画面。报价入口要同时交代面积/范围；工法入口要看清旧基层到覆盖动作；故事入口要有案例身份；生活入口可以先看成品再解释工艺。不能把所有片都套成价格开头或一秒一切。

“不拆不砸”是原基层覆盖方案的局部主张，不等于整项工程没有任何拆旧。P006拆浴柜、换洁具和P078拆旧包含可以与保留瓷砖并存，制作时必须说清对象。

材料演示型（P017/P073）容易吸引了解产品/施工的人；家里需要改造的业主更需要空间问题、服务范围和可进入的咨询入口。这是受众与内容匹配的判断，尚无流量/转化数据证明。

## 结尾不是统一的点赞尾巴

- 点赞/关注/以后找得到：降低动作门槛，目标是记住或再联系；不能把点赞当成需求确认。
- 找阿明/私信改哪里：让已有改造意向的人进入沟通；人名、城市和入口要真实可用。
- 头像→小区/改造位置→服务安排：把下一步说完整，跟踪应看有效需求、预约和方案，不只看播放。
- 免费上门/方案：必须知道服务半径、是否有条件及团队能否履行；参考片表达不是本企业服务规则。
- 生活效果/评论/结果收尾：保留内容完整性，R04/R09结果型结尾是反例，不应强行改成同一种咨询句。

P058与P070主体相同，仅结尾分别是“头像/小区/安排”和点赞，适合作为未来同题收口试验的候选；当前没有发布试验，也不能宣布哪种更有效。P029/P054/P064同属瓷砖师傅行业冲突，结尾有点赞和免费方案两个版本。

结尾动作按尾部文本规则计数，允许一条同时含多个动作；是检索字段，不是互斥分类，也不是转化成绩：点赞45条；服务/方案承诺23条；找人联系10条；关注13条；私信/后台咨询9条；提供位置/改造需求15条；评论/转发2条。
