# 专有词表

版本：v0.1，2026-11-16。配合《素材标注总纲》使用。

候选词由 AI 从主素材库的文件夹名里抽出，结论以李康的确认为准。状态只有两种：**已确认**（写明谁、哪天、凭什么确认）和**待确认**。待确认的词不能用来给素材打标签。

## 用法

- 人物身份和材料品名不让模型从画面里猜。只有两条路能给素材带上这类标签：素材所在文件夹命中下面的"文件夹写法"，或者人工看片确认。
- 标注中碰到词表里没有的叫法，先记成待确认，攒一批问李康，不直接进表。
- 词表每改一次，在文末"变更记录"加一行。

## 三、工序

状态：第三轮已问完（2026-11-16），下面四条都是李康确认的。

1. **微陶泥翻新的标准工序**：上门量房 → 遮蔽保护 → 基层处理（清洁瓷砖、填平砖缝）→ 滚涂底漆 → 第一遍批刮 → 第二遍批刮 → 打磨 → 罩面 → 卫生清洁 → 完工验收。
2. **"两遍"**：第一遍用陶砂打底，第二遍用陶泥收面。陶砂和陶泥在材料上都归微陶泥。
3. **罩面**："罩面""上罩面""滚涂罩面""实色罩面"合并成"罩面"一项。
4. **含砂中涂**：是和中源自己的另一种做法，和我们的"第一遍陶砂"不是同一道工序，分开记。

批刮是第几遍，只从文件夹名（如 `第一遍`、`第二遍`、`第一遍陶砂`）或人工确认带出，模型不从画面里猜。

文件夹里还出现、但没单独问的叫法：搬材料、拆砸、撕墙纸、铲墙皮、滚涂处理剂、垃圾清运、翻新对比、业主沟通。这些已能对应到总纲的画面类型和动作选项，不另立工序。

## 四、来源与限制

状态：第四轮已问完（2026-11-16），下面五条都是李康确认的。

1. **扒扒库（网采，22,622 条）**：都可以复用。陈瀚文标注库里给它们统一记的"权利待核"，按这条改为可用。水印、他人账号文字、他方品牌包装仍然作为画质瑕疵照常标出来。
2. **和中源工地素材（4,324 条）**：所有账号都能用。
3. **客户素材（8,463 条）**：没有人物的画面可以复用；有客户方人物的只用在该客户自己的片子里。
4. **`2其他\用不太上的`（559 条）**：照常标注，能用的就用。
5. 李康当时答的是没有写在文件夹名之外的禁用。之后看抽帧图时补了一条：`拍摄\招商\嘉贝乐工厂\口播` 里出现的人物不能用，已加进下表。所以看图确认时还可能再冒出新的禁用，冒出来就加进表里。
