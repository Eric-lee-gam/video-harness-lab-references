# 看图标注任务说明 v0.2

2026-11-16。依据：v0.1 试标 50 段后李康的逐段审核，和 5 个标注员报告的说明缺陷。还没有按这一版标过素材。每处改动的来由见同文件夹的 `v0.2改动说明.md`。

## 这是在做什么

我们有几万条装修翻新的实拍视频素材（用微陶泥这类材料在旧墙面、旧瓷砖上直接翻新）。剪短视频时，剪辑要按“这句口播该配哪类画面”去找镜头，所以每一小段素材都要有一个“画面类型”和几项基本事实。

你的任务是看抽帧图，给每一段填下面的 10 项。最要紧的是第 1 项画面类型，其余各项看不出来就选“看不清”，不要猜。

## 输入

`frames` 文件夹里的 `seg_01.jpg` 这类图片。每张图是同一段视频里连续约 3 秒的 4 帧，排成 2×2，时间顺序是左上、右上、左下、右下。

- 图四周的灰边是补边，不是画面内容。
- 原片太短时帧数不足 4 帧，空位上印着“无帧”两个字。
- 画面横倒或倒置时，按内容的正常方向去看，并在“拿不准的地方”里写“画面横倒”。

## 四条规矩

1. **只写看得见的。** 不判断人是谁，不判断材料的品名，不推测这是哪一户。
2. **每一项只能从给出的选项里选，原样照抄选项文字。**
3. **看不出来就选“看不清”。** 选“看不清”不算猜。有一点线索但不够定下来，也选“看不清”，把线索写进“拿不准的地方”。
4. **不要打开 `_对应表.csv`，也不要去查图片的来源。**

## 一段里前后不一样时怎么填

- 动作、朝向变了：按占帧数多的填。一样多时，按和画面类型对应的那个填。
- 人数：按人最多的那一帧数。
- 镜头连续地从一处移到另一处（跟拍、横移、摇）：不算换镜头，空间按占帧数多的填。
- 画面里有几个人各做各的：先定画面类型，再按撑起这个类型的那个人填朝向和主动作。比如前面的人对镜头讲话、后面的人在干活，类型是人物对镜头，朝向和主动作就按前面的人填。

## 每段要填的 10 项

### 1. 画面类型（单选）

| 代码 | 类型 | 怎么算 |
|---|---|---|
| V01 | 人物对镜头 | 人是主体，看着镜头说话或示意。人在成品房间里、工地里、室外都算 |
| V24 | 人物在现场（不看镜头） | 人在旧房或施工现场里走动、查看、比划，不看镜头，也没有和别人明显互动 |
| V02 | 握手/与客户沟通 | 人已经在屋里站定：握手、面对面交谈、一起低头看图纸、样板或同一样东西 |
| V03 | 团队上门/搬料搬物 | 人员进小区、上楼、进门；几个人站在门口或过道往房间里看；搬材料桶、工具、家具；开工前清空住户的物品。只有一个人也算 |
| V04 | 量房/水电/安装 | 用卷尺或测距仪测量；水电作业；安装洁具、灯具、柜体 |
| V05 | 施工·批刮覆盖 | 用刮板、批刀、抹子、小铲刀往墙面或地面上加料，包括补缝、补裂。拿着带料的工具站在施工面前也算，不要求每一帧都在抹 |
| V06 | 施工·滚涂 | 用滚筒或刷子往墙面或地面上涂 |
| V07 | 铲修旧墙/旧顶 | 往下铲墙皮、旧涂层 |
| V08 | 拆砸/贴砖 | 砸墙、拆瓷砖、拆洁具、拆橱柜；把拆下来的东西往外搬；贴瓷砖 |
| V09 | 铺保护膜/贴胶带 | 铺地膜、包家具、贴美纹纸 |
| V10 | 保洁/清扫（施工前后） | 施工现场的扫地、吸尘、清垃圾、用布擦地 |
| V11 | 材料桶（取料/搅拌/桶特写） | 画面主体是料桶：开桶、倒料、搅拌、从桶里取料、桶的特写 |
| V23 | 施工现场·其他 | 看得出是施工现场，但不属于上面任何一种。包括：打磨；现场全貌；贴了胶带保护膜或做了一半、没人干活的现场；有人在干活但看不清在干什么；一只手伸进施工现场比划 |
| V12 | 旧房旧态 | 还没动工的旧房间、旧瓷砖、污渍、破损，画面里没有人 |
| V13 | 成品空间（空镜） | 面层已经做完的空间或表面，画面里没有人。摆着家具日用品也算；顶上还吊着线、边角没收口也算 |
| V14 | 旧→新同镜转场 | 同一段里同一机位从旧状变到新状 |
| V15 | 成品里的人 | 做完的空间里有人在看、摸、走、生活，不看镜头 |
| V16 | 手摸/手指成品 | 画面主体是手和做完的表面：摸、敲、指、比划 |
| V17 | 成品日常清洁 | 入住后拖地、擦洗做完的表面 |
| V18 | 演示·喷水冲洗 | 往表面喷水、冲水、泼水做演示 |
| V19 | 演示·弯折样板/揭薄层 | 弯折样板，或揭起一层薄料做演示 |
| V20 | 演示·刮擦/擦污 | 用硬物刮、用布擦污渍做演示 |
| V21 | 老楼/城市外景 | 楼栋外观、小区、街道、城市地标，人不是主体 |
| V22 | 其他 | 看得清，但以上都不是 |
| V00 | 看不清 | 连是不是施工现场、有没有人都看不出 |

**两类都像的时候，按下面的顺序定，先对上的算：**

1. 有人看着镜头说话或示意，而且是画面主体：人物对镜头。
2. 有人在施工，工具看得清：选对应的施工类（V04 到 V11）。
3. 有人在施工，工具或动作看不清：施工现场·其他。**不要按猜的工具去选批刮、滚涂或清扫**，把可能是哪两类写进“拿不准的地方”。
4. 画面主体是一只手和一个表面：表面是做完的选手摸/手指成品，是施工现场选施工现场·其他。
5. 几个人之间有互动：按上表 V02、V03 的写法分。
6. 有人但没有施工、没有互动、不看镜头：做完的空间选成品里的人，旧房或施工现场选人物在现场。
7. 没有人：旧的选旧房旧态，做完的选成品空间，做了一半或贴着保护的选施工现场·其他。

其他容易混的：

| 容易混 | 怎么分 |
|---|---|
| 批刮 / 铲修 | 往面上加料是批刮（含补缝补裂），往下铲东西是铲修 |
| 批刮 / 滚涂 | 看工具：刮板、批刀、抹子是批刮，滚筒、刷子是滚涂 |
| 批刮 / 材料桶 | 工具在桶里是材料桶，工具在墙面地面上是批刮 |
| 拆砸 / 搬料搬物 | 搬的是拆下来的废料、旧柜体，算拆砸；搬的是材料、工具、住户的东西，算搬料搬物 |
| 保洁清扫 / 成品日常清洁 | 施工现场的清理是保洁，住进去以后的拖地擦洗是日常清洁 |

### 2. 空间（单选）

卫生间 / 厨房 / 客厅餐厅 / 卧室 / 阳台 / 楼梯过道 / 入户门口 / 小区楼栋外 / 城市街景或地标 / 展厅 / 车旁或仓库 / 样板台 / 室内，分不清房间 / 看不清

- 只有看见下面这些东西才填具体房间：马桶、蹲便器、淋浴、洗手台是卫生间；灶台、水槽、橱柜、油烟机是厨房；床是卧室；沙发、餐桌、电视是客厅餐厅。
- 只凭地漏、管口、水龙头、瓷砖、窗户，不填具体房间，选“室内，分不清房间”。
- 施工特写只看得见一面墙或一块地：选“室内，分不清房间”。
- 厨房和餐厅连在一起：按画面主体所在的一边填。
- 镜头在门外往里拍：按门里的房间填。
- 室内的走道算“楼梯过道”。

空间最后以文件夹名和整条视频的信息为准，这里填的只用来核对，所以不要为了填满去猜。

### 3. 阶段（单选）

按“面层做到哪一步”判，不看有没有人住。

| 选项 | 怎么算 |
|---|---|
| 旧状（未动工） | 面是旧的，没有保护膜、胶带和新料。住着人、摆着东西也算 |
| 拆除铲除中 | 正在拆、砸、铲，或地上有拆下来的碎块、旧柜体 |
| 保护与基层处理 | 贴了保护膜或胶带；或在清洁、填缝；或用滚筒在旧瓷砖、旧墙面上刷底。面上还没有大片新料 |
| 上料施工中 | 正在用抹子、刮板上料；或面上的料只抹了一部分 |
| 罩面收尾 | 整个面已经同色成形，正在用滚筒、刷子或打磨工具处理；或在做完工后的清理 |
| 安装收口 | 面层做完，正在装柜体、洁具、灯具、五金 |
| 施工中途（没人干活） | 看得出没做完（地面还是毛坯、只做了一部分、保护还没撤），现场没有人在干活 |
| 完工空房 | 面层做完，没有家具和日用品。顶上还吊着线、边角没收口这类小尾巴不影响 |
| 入住使用 | 做完的面，摆着家具或日用品。只有一两样小东西不算 |
| 非现场 | 不在翻新的房子里：室外、车旁、展厅、样板台演示 |
| 其他 | 看得清但套不上，比如不是翻新项目的毛坯工地。在“拿不准的地方”写明 |
| 看不清 | 特写里只有一小块面，判断不了；或分不出是翻新前还是翻新后 |

人在房子里对镜头讲话，阶段按房子的情况填，不填“非现场”。

### 4. 人数（单选）

0 / 1 / 2 / 3以上

- 只露出手、手臂或脚也算 1 个人，拍摄者自己伸进画面的手脚也算。
- 镜子里的倒影、窗外或远处无关的路人不算。
- 两只手分不出是不是同一个人，按 1 个人算。

### 5. 朝向（单选）

看镜头 / 露脸但不看镜头 / 背面 / 看不见头脸 / 无人

- 按视线判，不按身体朝哪边。身体正对镜头但低头干活，是“露脸但不看镜头”。
- 侧脸算“露脸但不看镜头”。
- 只露出手脚，或头在画面外，是“看不见头脸”。

### 6. 主动作（单选）

- 施工类：批刮 / 滚涂 / 刷涂 / 搅拌 / 倒料取料 / 打磨 / 铲除 / 拆砸 / 拆卸 / 贴砖 / 铺膜贴胶带 / 安装 / 测量 / 清扫吸尘 / 收拾整理
- 人物类：握手 / 交谈讲解 / 指向示意 / 手势 / 查看 / 行走 / 走入进门 / 搬运 / 挥手 / 转身 / 开门推门 / 展示
- 成品与演示类：手摸 / 展示细节 / 拖地擦洗 / 喷水冲水 / 弯折 / 刮擦敲击
- 遮镜
- 无动作 / 其他 / 看不清

几项的意思：

| 选项 | 意思 |
|---|---|
| 拆卸 | 用工具把柜门、洁具、五金卸下来，不是砸 |
| 收拾整理 | 开工前把住户的东西拿走、装袋、挪开 |
| 查看 | 站着或走着看墙、看顶、看手机，手上没有别的动作 |
| 手势 | 竖拇指、比数字这类，不是指向某处 |
| 展示 | 把东西举起来或递到镜头前给人看 |
| 展示细节 | 镜头凑近拍材料表面的质感、纹理，手只是带一下 |
| 遮镜 | 手或物体盖住镜头 |
| 拖地擦洗 | 用拖把或布擦，施工现场和入住后都用这一项 |

### 7. 视角（单选）

第一视角 / 旁观拍摄 / 看不清

- 第一视角：拍的人自己的手、脚或身体从画面边缘伸进来，边拍边指、边拍边摸、边走边看。
- 没有看到拍摄者的手脚入画，一律填“旁观拍摄”。

### 8. 转场镜头（单选）

是 / 否

“是”指这一段里有拍的人有意做的、用来接上一个或下一个镜头的动作：

- 手或物体盖住镜头，画面一片糊、一片黑或一片纯色
- 手从镜头前划过，或伸向镜头
- 对着镜头比一个手势，然后画面空掉
- 推开门露出房间
- 人转身，带出后面的画面

填“是”时，在“看见了什么”里写明是哪一种。

**开头或结尾有一帧全糊、全黑、纯色，先当遮镜看**，不当废帧，也不算多画面。其余各项按看得清的那几帧填。（印着“无帧”的空位不是遮镜。）

### 9. 多画面（单选）

是 / 否

只有场景或机位**突然跳变**才填“是”。连续的跟拍、横移、摇镜，机位慢慢变近变远，都填“否”。遮镜转场也填“否”。

填“是”时，前 8 项按帧数多的那个镜头填，一样多按前一个填。

### 10. 看见了什么、把握、拿不准的地方

- **看见了什么**：一句话，40 字以内，只写画面里看得见的东西和动作。
- **把握**：确定 / 不确定。**只针对第 1 项画面类型。** 画面类型是在两类之间选的，或是按上面的顺序勉强定的，填“不确定”。其余各项拿不准的直接选“看不清”，不影响这一项。
- **拿不准的地方**：写清哪一项、卡在哪里、可能是哪两个选项。没有就留空。不限字数。

## 输出格式

一段一行 JSON，写进指定的结果文件（UTF-8）。键名和选项文字都要和本说明完全一致：

```json
{"seg": "seg_01", "画面类型代码": "V05", "画面类型": "施工·批刮覆盖", "空间": "室内，分不清房间", "阶段": "上料施工中", "人数": "1", "朝向": "看不见头脸", "主动作": "批刮", "视角": "旁观拍摄", "转场镜头": "否", "多画面": "否", "看见了什么": "一只手持刮板在旧瓷砖墙面上横向抹灰色的料", "把握": "确定", "拿不准的地方": ""}
```

## 做法

一张一张看，看一张填一张，不要看了几张就按印象批量填。全部看完再一次写入结果文件。

## 填完后会自动检查的规则

- 画面类型是批刮覆盖：主动作是批刮，阶段是上料施工中
- 画面类型是滚涂：主动作是滚涂或刷涂，阶段是保护与基层处理或罩面收尾
- 画面类型是成品空间：人数是 0，阶段是完工空房或入住使用
- 画面类型是成品里的人：人数至少 1，阶段是完工空房或入住使用
- 画面类型是人物对镜头：人数至少 1，朝向是看镜头
- 画面类型是旧房旧态：人数是 0，阶段是旧状（未动工）
- 人数是 0：朝向是无人
- 主动作是遮镜：转场镜头是“是”
