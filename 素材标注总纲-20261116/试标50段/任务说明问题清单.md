# 任务说明问题清单（试标 50 段，云端模型）

2026-11-16。来源：5 个子智能体各标 10 段后，各自报告的“说明里不清楚、矛盾、缺选项的地方”，由 AI 去重整理。括号里是出问题的段号。

这份清单还没有经过李康审核。哪些要改、怎么改，等人工审完 50 段再定。

## 机器检查的结果

| 项 | 结果 |
|---|---|
| 标完的段数 | 50 / 50 |
| 选项不合规（用了说明以外的文字） | 0 |
| 一致性规则不通过 | 0 |
| 把握填“不确定” | 34 段 |
| 空间填“看不清” | 21 段 |
| 阶段填“看不清” | 11 段 |
| 主动作填“看不清”或“其他” | 9 段（看不清 4、其他 5） |
| 多画面填“是” | 0 段 |

按总纲第七节的触发条件，“看不清”超过两成就要回头查抽帧和定义。空间（42%）和阶段（22%）都超了。

## 一、阶段：定义最弱的一项

1. **各选项没有定义。** “上料施工中”和“罩面收尾”看图分不出：面已经发白还在抹或滚，不知道是哪一遍（02、20、22、29、37、41、44、47、48）。
2. **“完工空房”和“入住使用”没有判据**，有几样生活用品算入住没写（04、16、17、40）。
3. **翻新前住着人的旧房**，“旧状（未动工）”和“入住使用”都说得通（03、07、27、32）。
4. **缺选项：** 装柜子这类安装阶段（05）；面层做完但没收口、没人干活的半完工现场（09、34、45）；非翻新类的毛坯工地（30）。阶段也没有“其他”。
5. **“非现场（演示、口播、外景）”和现场口播冲突**：人在完工房间或施工现场里对镜头讲话，按行为该填非现场，按看得见的该填现场（08、46）；室外搬料算不算外景也没写（33）。

## 二、空间：四成填了“看不清”

6. **施工特写只看得见墙面或地面**，认不出房间（01、04、10、11、12、13、20、22、23、24、25、31、35、37、42、46、47、50）。建议加一项“室内，分不清房间”，和真正看不清的画面分开。
7. **旧瓷砖房里厨房、卫生间、阳台特征几乎一样**。能不能凭地漏、管口、水龙头推断没有写，各人处理不一致（01、05、09、29、36、41、44）。
8. **没有合适选项或有两个都对：** 开放式厨房连餐厅（40）；镜头在门外拍门内（34）；小区楼栋外和车旁同时成立（33）；室内过道算不算“楼梯过道”（28）；镜头从一个房间摇到另一个房间（27、49）。

## 三、画面类型

9. **没有“看不清”选项。** 看得出在施工但看不清工具时，只能塞进“施工现场·其他”，这一类就混进了“都不是”和“分不清”两种情况（02、37、42、48）。
10. **类型重叠，没有优先顺序：**
    - 人物对镜头 / 成品里的人：人站在完工房间里对镜头讲（08）
    - 成品里的人 / 人物在现场：人在完工空房里走动查看（26、38）
    - 握手沟通 / 成品里的人 / 人物在现场：几个人一起看一个空间（34）
    - 旧房旧态 / 施工现场·其他：保护做好了但没人干活（21）
    - 成品空间 / 施工现场·其他：面层做完但没收口（09）
    - 拆砸 / 搬料搬物：拆除现场往外搬废料（49）
    - 前景人物对镜头、背景有人施工（46）；远景全貌里有一个人在干活（48）
11. **铲修的定义和区分规则矛盾。** 定义写“往下铲，或修补基层”，区分规则写“往面上加料是批刮”，补裂缝两边都占（24）。
12. **定义没覆盖的画面：** 单人进门算不算“团队上门”（14）；开工前收拾住户的物品（19）；拆橱柜（18）；用抹布擦施工现场的地（25）；只有一只手伸进来比划（23）。“拆砸/贴砖（传统做法）”的“传统做法”几个字让人犹豫正常拆旧算不算。
13. **“完工表面”看特写判断不了。** 手摸墙面的特写看不出是不是成品（04、17）；有生活用品的完工空间算不算“空镜”（39、40）。
14. **批刮要不要求帧里看得到抹的动作。** 人拿着带料的抹子站在墙前、没在抹（01）；工具被身体挡住（36）。

## 四、主动作

15. **缺选项：** 查看、行走、看手机（26、30、38、50）；举起东西给镜头看（08）；拆卸（18）；收拾整理（19）；竖拇指这类手势（23）。“人物在现场”的定义写了“走动、查看、比划”，主动作里却没有对应项。
16. **一段里动作变了按哪个填**，没有规定（14、26、28、33、36、49）；多人各做各的按谁填（34）。

## 五、人数和朝向

17. **“对镜头”指身体朝向还是视线**，没写（02、33、46）。正脸看得见但低头干活，现有选项都不贴切（11、13、18）。
18. **“侧面或背面”和“看不见脸”重叠**：纯背影两个都说得通（36、41、42、44）；头在画面外但身体在（24、28、31）。
19. **人数的边界没写：** 拍摄者伸进画面的手脚算不算（01、10、25、49）；各帧人数不同取哪个（17、32、49）；镜子里的倒影、远处的路人（49）；两只手是不是同一个人（20）；多人时“最主要的人”按什么定（03、07、32、34）。

## 六、多画面

20. **“按第 1 帧填”在首帧模糊时行不通**（09、15）。
21. **连续运镜算不算换镜头**：手持跟拍跨房间、快速横移（27、43、45、49）；机位变了但场景没变（12、37、40）。50 段里没有一段被判为“是”，说明这一项现在基本没起作用。

## 七、把握和格式

22. **选了“看不清”时把握填什么**没写，5 个子智能体都按“不算猜，填确定”处理。有一点依据但不充分时，该选“看不清”还是“猜一个再标不确定”也没写。
23. **“40 字以内”和“括号里写原因”冲突**，几乎每段都超。建议原因另设一栏。

## 八、抽帧本身的问题

24. **有的画面横倒了 90 度**，人很小，四周灰边很大，直接导致看不清（11、42）。这是抽帧脚本要处理的，不是模型的问题。
25. **原片太短时帧数不足**（16、17、37）。

## 这次试标说明了什么

- **格式上可行。** 50 段全部按固定选项填写，没有自造选项，也没有自相矛盾。
- **模型会照实说拿不准**，没有硬猜，而且能具体指出卡在哪条定义上。
- **“空间”和“阶段”不适合只靠 3 秒的 4 帧来判。** 这两项更适合从同一条视频的更长范围、或从文件夹名里带出来，再由模型核对。
- **画面类型的准确率现在还不知道**，要等李康审完才有数。
