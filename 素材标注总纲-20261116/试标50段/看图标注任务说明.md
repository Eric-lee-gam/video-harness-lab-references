# 看图标注任务说明（试标版 v0.1）

## 这是在做什么

我们有几万条装修翻新的实拍视频素材（用微陶泥这类材料在旧墙面、旧瓷砖上直接翻新）。剪短视频时，剪辑要按“这句口播该配哪类画面”去找镜头，所以每一小段素材都要有一个“画面类型”和几项基本事实。

你的任务是看抽帧图，给每一段填下面的 8 项。你填的结果会由人逐条审核，用来判断**这份说明写得清不清楚**。所以拿不准的时候，照实选“看不清”并写出卡在哪里，比硬猜一个更有用。

## 输入

`frames` 文件夹里的 `seg_01.jpg` 这类图片。每张图是同一段视频里连续约 3 秒的 4 帧，排成 2×2，时间顺序是左上、右上、左下、右下。

- 图四周的灰边是补边，不是画面内容。
- 原片太短时帧数不足 4 帧，空位是纯色。

## 三条规矩

1. **只写看得见的。** 不判断人是谁，不判断材料的品名，不推测这是哪里、哪一户。
2. **每一项只能从给出的选项里选，原样照抄选项文字。** 没有合适的就选“其他”或“看不清”，并在“看见了什么”里说明。
3. **不要打开 `_对应表.csv`，也不要去查图片的来源。** 那里面有答案线索，看了这次测试就废了。

## 每段要填的 8 项

### 1. 画面类型（单选）

| 代码 | 类型 | 怎么算 |
|---|---|---|
| V01 | 人物对镜头 | 人是主体，脸朝镜头说话或示意 |
| V24 | 人物在现场（不看镜头） | 人在房间或工地里走动、查看、比划，不看镜头，也没有和别人明显互动 |
| V02 | 握手/与客户沟通 | 两人或多人之间握手、交谈、一起看图纸或样板 |
| V03 | 团队上门/搬料搬物 | 人员进小区、上楼、进门；搬材料桶、工具或家具 |
| V04 | 量房/水电/安装 | 用卷尺或测距仪测量；水电作业；安装洁具、灯具、柜体 |
| V05 | 施工·批刮覆盖 | 用刮板、批刀、抹子往墙面或地面上抹料 |
| V06 | 施工·滚涂 | 用滚筒或刷子往墙面或地面上涂 |
| V07 | 铲修旧墙/旧顶 | 往下铲墙皮、旧涂层，或修补基层 |
| V08 | 拆砸/贴砖（传统做法） | 砸墙、拆瓷砖、拆洁具；贴瓷砖 |
| V09 | 铺保护膜/贴胶带 | 铺地膜、包家具、贴美纹纸 |
| V10 | 保洁/清扫（施工前后） | 施工现场的扫地、吸尘、清垃圾 |
| V11 | 材料桶（取料/搅拌/桶特写） | 画面主体是料桶：开桶、倒料、搅拌、从桶里取料、桶的特写 |
| V23 | 施工现场·其他 | 正在施工的现场，但不属于上面任何一种施工画面（如打磨、施工中的现场全貌） |
| V12 | 旧房旧态 | 还没动工的旧房间、旧瓷砖、污渍、破损 |
| V13 | 成品空间（空镜） | 完工后的空间或表面，画面里没有人 |
| V14 | 旧→新同镜转场 | 同一段里同一机位从旧状变到新状 |
| V15 | 成品里的人 | 完工后的空间里有人（生活、参观、展示） |
| V16 | 手摸/手指成品 | 画面主体是手和完工表面：摸、敲、指 |
| V17 | 成品日常清洁 | 入住后拖地、擦洗完工表面 |
| V18 | 演示·喷水冲洗 | 往表面喷水、冲水、泼水做演示 |
| V19 | 演示·弯折样板/揭薄层 | 弯折样板，或揭起一层薄料做演示 |
| V20 | 演示·刮擦/擦污 | 用硬物刮、用布擦污渍做演示 |
| V21 | 老楼/城市外景 | 楼栋外观、小区、街道、城市地标 |
| V22 | 其他 | 以上都不是 |

容易混的几对：

| 容易混 | 怎么分 |
|---|---|
| 人物对镜头 / 人物在现场 | 看不看镜头 |
| 人物在现场 / 握手沟通 | 有没有两人之间的互动 |
| 批刮 / 铲修 | 往面上加料是批刮，往下铲东西是铲修 |
| 批刮 / 滚涂 | 看工具：刮板批刀是批刮，滚筒是滚涂 |
| 批刮 / 材料桶 | 工具在桶里是材料桶，工具在墙面地面上是批刮 |
| 成品空间 / 旧房旧态 / 施工现场·其他 | 看阶段：完工、未动工、施工中 |
| 保洁清扫 / 成品日常清洁 | 施工现场的清理是保洁，住进去以后的拖地擦洗是日常清洁 |
| 手摸成品 / 人物在现场 | 画面主体是手和表面，才算手摸成品 |

### 2. 空间（单选）

卫生间 / 厨房 / 客厅餐厅 / 卧室 / 阳台 / 楼梯过道 / 入户门口 / 小区楼栋外 / 城市街景或地标 / 展厅 / 车旁或仓库 / 样板台 / 看不清

### 3. 阶段（单选）

旧状（未动工） / 拆除铲除中 / 保护与基层处理 / 上料施工中 / 罩面收尾 / 完工空房 / 入住使用 / 非现场（演示、口播、外景） / 看不清

### 4. 人数（单选）

0 / 1 / 2 / 3以上

只露出手、手臂或脚也算 1 个人。

### 5. 朝向（单选）

对镜头 / 侧面或背面 / 看不见脸 / 无人

多人时按画面里最主要的那个人填。只露出手脚的填“看不见脸”。

### 6. 主动作（单选）

- 施工类：批刮 / 滚涂 / 刷涂 / 搅拌 / 倒料取料 / 打磨 / 铲除 / 拆砸 / 贴砖 / 铺膜贴胶带 / 安装 / 测量 / 清扫吸尘
- 人物类：握手 / 交谈讲解 / 指向示意 / 走入进门 / 搬运 / 挥手 / 转身 / 开门推门
- 成品与演示类：手摸 / 拖地擦洗 / 喷水冲水 / 弯折 / 刮擦敲击
- 无动作 / 其他 / 看不清

### 7. 多画面（单选）

是 / 否

4 帧明显来自两个不同的镜头（场景或机位突然换了）填“是”，这时前 6 项按第 1 帧填。

### 8. 看见了什么、把握

- 看见了什么：一句话，40 字以内，只写画面里看得见的东西和动作。
- 把握：确定 / 不确定。任何一项是猜的，就填“不确定”，并在“看见了什么”后面用括号写明哪一项拿不准、为什么。

## 输出格式

一段一行 JSON，写进指定的结果文件（UTF-8）。键名和选项文字都要和本说明完全一致：

```json
{"seg": "seg_01", "画面类型代码": "V05", "画面类型": "施工·批刮覆盖", "空间": "卫生间", "阶段": "上料施工中", "人数": "1", "朝向": "看不见脸", "主动作": "批刮", "多画面": "否", "看见了什么": "一只手持刮板在旧瓷砖墙面上横向抹灰色的料", "把握": "确定"}
```

## 做法

一张一张看，看一张填一张，不要看了几张就按印象批量填。全部看完再一次写入结果文件。
